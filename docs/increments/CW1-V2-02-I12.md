## Required observable contract

| Field | POST omitted | PUT omitted | PATCH omitted | Explicit null | Concrete / blank |
| --- | --- | --- | --- | --- | --- |
| `name` | required | required | preserve | reject | trim; nonblank; maximum 100 characters |
| `rd` | SQL null | preserve | preserve | clear | trim; maximum 21 characters; blank distinct from null |
| `enforce_unique` | `true` | preserve | preserve | reject | explicit `false` stays false |
| `description` | `""` | preserve | preserve | reject | trim; blank allowed; maximum 200 characters |
| `comments` | `""` | preserve | preserve | reject | trim; blank allowed; no invented length bound |

All four text fields reject NUL with `null_characters_not_allowed`. Do not
reject every control character or add an RFC route-distinguisher parser:
pinned RD accepts arbitrary text inside its length envelope. Keep blank RD
and SQL null distinct in domain state, snapshots, raw rows, reload, REST,
and representable gRPC intent.

Missing required name is `required`, explicit null is `null`, and supplied
blank/trimmed whitespace is `blank`. Length is Unicode character count, not
UTF-8 byte count. Mixed failures aggregate deterministically by field and
reason, without duplicates or a fabricated empty-update failure. Required/
null intent must take precedence over fallback-name errors. Length and NUL
checks are independent: an overlength RD containing NUL must retain both
`rd/max_length` and `rd/null_characters_not_allowed`, even when RD parsing
fails before a typed value exists. The same two-reason case applies to name
and description. Preview validation must not mutate loaded state.

POST/PUT gRPC wrappers cannot express independent explicit-null strings or
booleans; absence means omission. For each known PATCH mask path, an absent
wrapper means shared explicit-null intent (RD clears; other fields reject).
Unknown masks remain fail-closed. Only equivalent representable intent earns
same-core parity. No protobuf change is needed.

The existing strict JSON string/boolean envelope is retained. DRF also accepts
some numeric/string coercions; this packet does not close those differences.
Malformed/surrogate UTF-8 and Python-versus-Go control-whitespace trimming
remain deferred, not declared exact. Ordinary valid Unicode text and the
explicitly tested NUL rejection are owned. Empty PATCH and unchanged-save UX
remain separately unclaimed; do not change or assert their policy as baseline
