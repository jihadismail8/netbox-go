reject every control character or add an RFC route-distinguisher parser:
pinned RD accepts arbitrary text inside its length envelope. Keep blank RD
and SQL null distinct in domain state, snapshots, raw rows, reload, REST,
and representable gRPC intent.

blank/trimmed whitespace is `blank`. Length is Unicode character count, not
UTF-8 byte count. Mixed failures aggregate deterministically by field and
reason, without duplicates or a fabricated empty-update failure. Required/
null intent must take precedence over fallback-name errors. Length and NUL
checks are independent: an overlength RD containing NUL must retain both
`rd/max_length` and `rd/null_characters_not_allowed`, even when RD parsing
fails before a typed value exists. The same two-reason case applies to name
and description. Preview validation must not mutate loaded state.
