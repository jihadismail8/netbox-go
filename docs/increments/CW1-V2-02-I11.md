`duplex` choices are exact and untrimmed. The pinned custom ChoiceField turns
nonnullable type null into blank and rejects it as a blank choice; it must not
silently use a generic nullable-char diagnostic. Ordinary nonnullable fields
retain their required/null/blank diagnostics.

MTU/speed requests preserve signed `int64` intent in application commands.
REST decoding retains the existing exact integral JSON-number grammar within
that signed envelope; malformed, nonintegral, or out-of-envelope values fail
closed. gRPC already provides signed wrappers. Pure domain parsers validate
before conversion to existing unsigned domain values. MTU below 1 and above
65536 receive the corresponding minimum/maximum diagnostics; speed below 0
and above 2147483647 do likewise. Invalid numbers must never wrap, saturate,
or be reclassified as a different bound failure. General coercion, alternate
number envelopes, and exact diagnostics outside the signed envelope are not
promoted by I11.
